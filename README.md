# Sidcup Family Golf — Website UI Clone

A front-end recreation of the Sidcup Family Golf landing page, built with HTML, CSS, and JavaScript. The project focuses on a full-screen hero section, scrolling page sections, custom cursor effects, and GSAP-powered animations.

**Repository:** https://github.com/nirbhaycse/sidcup_website_clone

## Features

- Fixed navigation layout.
- Full-screen background video hero.
- Animated text and scrolling content sections.
- Custom cursor and cursor-blur effects.
- Scroll-triggered transitions using GSAP and ScrollTrigger.
- Remix Icon icon font.
- External image, video, and logo assets.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GSAP 3 and ScrollTrigger
- Remix Icon

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/nirbhaycse/sidcup_website_clone.git
   cd sidcup_website_clone
   ```

2. Open `index.html` in a browser. For the most reliable behaviour, use a local static server such as the Live Server extension in VS Code.

No build step is currently configured. GSAP, Remix Icon, video, and image assets are loaded from external URLs, so an internet connection is needed for those resources.
